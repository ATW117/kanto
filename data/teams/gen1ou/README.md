# Gen 1 OU team pool

## Layout

| File | What |
| --- | --- |
| `teams.jsonl` | **The pool.** 1,000 distinct teams, one JSON object per line, in the team schema of docs/DESIGN.md. Generated by `generate.py` (below). |
| `split/train.jsonl`, `split/eval.jsonl` | Deterministic 90/10 train / held-out split of the pool (895 / 105 teams), written by `split.py`. Load them as `data/teams/gen1ou:train` / `:eval`. |
| `split.py` | Writes the split. A team is in `eval` iff SHA-256 of its canonical JSON (sorted keys, no whitespace) is 0 mod 10, so the assignment depends only on the team itself. `--check` verifies the files are current. Re-run it after editing `teams.jsonl`. |
| `validate.py` | Schema + legality check (Showdown's own `TeamValidator` for `gen1ou`, run through `validate_ps.js`). |
| `validate_ps.js` | Node helper for `validate.py`. Needs a `pokemon-showdown` npm package. |
| `generate.py` | Samples teams from Smogon usage statistics. It wrote `teams.jsonl`. |
| `usage/gen1_names.json` | Showdown id to display-name map for Gen 1 species and moves (from `Dex.mod('gen1')`). |

The env loaders (`TeamSource::from_spec`, `pokemon_env.VecEnv(teams=...)`) check every team for
Gen 1 legality: Species Clause, learnsets and a consistent HP DV. They reject out-of-range DVs, levels
and unknown names. The whole pool passes; `validate=False` turns off the legality part.

**Format choice: one `teams.jsonl`, not one file per team.** Thousands of files would be unwieldy. A
loader should read `data/teams/gen1ou/*.jsonl` (one team per non-empty line), and may also accept
`*.json` (a single team object, or a list of them) for hand-written teams. `usage/` is a
subdirectory, so a non-recursive `*.json` glob of this directory does not pick up the stats files.

Example line (formatted here for reading):

```json
{"name":"generated/0/00000","source":"generated:smogon-chaos/gen1ou-1630-2026-09.json:seed0","pokemon":[
  {"species":"Zapdos","moves":["Agility","Thunderbolt","Thunder Wave","Drill Peck"],"level":100}, ...]}
```

- Names use Showdown display spelling (`Soft-Boiled`, `Self-Destruct`, `Farfetch’d` with U+2019).
- `dvs` and `exp` are written only when they differ from the max (DV 15, stat exp 65535). The
  generated pool uses the defaults throughout.
- `dvs.hp` is always derived the Gen 1 way, from the low bits of Atk/Def/Spe/Spc. `validate.py`
  enforces this.
- Every team has 6 Pokémon at level 100, each with up to 4 moves. Slot 0 is the first species
  sampled (the most likely lead).

## Provenance and licenses

`teams.jsonl` is self-generated: `python3 generate.py -n 1000 --seed 0 --stats
usage/gen1ou-1630-2026-09.json -o teams.jsonl`, then `python3 split.py`. The input was Smogon's
public Gen 1 OU usage statistics for September 2026, 1630+ rating, 11,702 battles
(`https://www.smogon.com/stats/2026-09/chaos/gen1ou-1630.json`). Only aggregate counts are used
(species usage, teammate co-occurrence and move frequencies); no individual player's team is
copied. The stats file itself is not redistributed here, because Smogon publishes it without an
explicit license.

Pool composition: 26 species, dominated by the usual OU core (Tauros, Snorlax, Chansey, Exeggutor,
Starmie, Alakazam, Jynx, Gengar, Rhydon, Zapdos, Cloyster). All sets use max DVs and stat exp.

Real ladder teams (for example, converted from the Metamon project's `metamon-teams` dataset)
load the same way: any `.jsonl` file or directory in this schema works as `teams=`. They are not
shipped because the dataset carries no license of its own.

## Validation

```
python3 validate.py                 # all *.jsonl / *.json here; exit 0 iff all pass
python3 validate.py -v some.jsonl   # print every failing team
python3 validate.py --schema-only   # no Node needed
```

Layer 1 (Python) checks the schema: 1-6 Pokémon, 1-4 distinct moves, distinct species, level 1-100,
DVs 0-15 with a consistent Gen 1 HP DV, and stat exp 0-65535.

Layer 2 runs Showdown's `TeamValidator.get('gen1ou')`. This covers learnsets (including the
"can't be transferred from Gen 2" rule, i.e. Stat Tradeback Clause), the Uber ban (Mewtwo, Mew),
the Species Clause, the OHKO Clause (Fissure, Horn Drill, Guillotine), the Evasion Moves Clause
(Double Team, Minimize), and Showdown's gen1 Standard bans on Dig and Fly. Sleep, Freeze and
Desync Clause Mods are battle-time rules, so a validator cannot check them. The engine/env is
responsible for those if it wants Showdown parity. Point `--ps` (or `PS_PATH`) at a
`pokemon-showdown` npm package. Node comes from `--node`, `$NODE`, `PATH`, or the newest
`~/.nvm/versions/node/*`.

Last run (pokemon-showdown 0.11.11, Node 22):

## generate.py

```
python3 generate.py -n 500 --seed 1 --stats usage/gen1ou-1630-2026-09.json -o extra.jsonl
python3 validate.py extra.jsonl
```

The generator samples the first species by usage share and each later species by usage times
teammate lift. The lift is P(t|s)/P(t), from chaos `Teammates` counts. No species repeats, and
species under `--min-usage` (default 1%) are dropped. Moves are drawn by the species' move usage
without replacement, after dropping moves seen on fewer than 2% of the species' sets and the
clause-banned moves. Levels are 100 with max DVs and stat exp. Download a stats file from
`smogon.com/stats/<YYYY-MM>/chaos/gen1ou-<cutoff>.json` and pass it with `--stats`.
