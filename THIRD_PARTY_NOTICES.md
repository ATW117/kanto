## Pokémon Showdown

<https://github.com/smogon/pokemon-showdown>, version 0.11.11 (the npm package
`pokemon-showdown@0.11.11`). Copyright (c) 2011-2026 Guangcong Luo and other contributors. MIT.

Derived from it:

- **Simulator logic (ported to Rust).** `crates/kanto-gen1` (battle flow, every Gen 1 move,
  status and volatile handler, damage calculation, request building, protocol messages) is a
  translation of Showdown's `data/mods/gen1/*` and the parts of `sim/battle.ts`,
  `sim/battle-actions.ts`, `sim/battle-queue.ts`, `sim/pokemon.ts` and `sim/side.ts` that Gen 1
  uses. `crates/kanto-core` ports `sim/prng.ts` (`prng.rs`), `Battle#speedSort` /
  `comparePriority` (`sort.rs`), and `Battle#add`/`addSplit`/`hint`/`attrLastMove` plus
  `extractChannelMessages` (`proto.rs`). Function names in comments refer to the Showdown
  originals.
- **Data tables (generated).** `crates/kanto-data/src/gen1.rs` is generated by
  `tools/gen_sim_data.js` from Showdown's `Dex.mod('gen1')`: species stats and types, move data,
  secondaries and flags, the type chart, Metronome's move list and name aliases.
  `crates/kanto-env/src/data/generated.rs` (learnsets and the Gen 1 random-battle sets) and
  `data/teams/gen1ou/usage/gen1_names.json` (display names) are generated from the same package.
- **Test drivers.** `parity/showdown/runner.js` and `data/teams/gen1ou/validate_ps.js` load and
  drive an installed copy of Showdown; Showdown itself is not distributed with kanto.
- **Recorded traces.** `parity/fixtures/` holds compact records (choices, state hashes) of
  battles played by Showdown, used as regression tests.

## pkmn/engine

<https://github.com/pkmn/engine>, included as the git submodule `third_party/pkmn-engine` (pinned
commit; it carries its own `LICENSE`). Copyright (c) 2021-2026 pkmn contributors. MIT.

Derived from it:

- **Optional backend.** `crates/pkmn-sys` (FFI declarations for `pkmn.h`, layout constants) and
  `crates/kanto-env/src/pkmn1.rs` (battle serialisation following the engine's documented byte
  layout, `src/lib/gen1/README.md` and `src/data/layout.json`) and
  `crates/kanto-env/src/protocol.rs` (parser for the engine's binary protocol, `docs/PROTOCOL.md`).
  These are only compiled with the `pkmn` cargo feature.
- **Data tables (generated).** In `crates/kanto-env/src/data/generated.rs`, species and move ids,
  base stats, types, move data and the type chart come from the engine's `src/data/data.json`
  (`tools/gen_data.mjs`). The observation encoding uses pkmn's type order.
- **Test patches.** `parity/showdown/patches.js` ports the engine's "patched Showdown"
  (`src/test/showdown.ts`) to Showdown 0.11.11.
- **C driver.** `tests/c/driver.c` is modelled on the engine's `examples/c/example.c`.

## Team data

`data/teams/gen1ou/teams.jsonl` was generated for kanto by `data/teams/gen1ou/generate.py` from
aggregate Smogon usage statistics (counts only; the statistics file is not redistributed). See
`data/teams/gen1ou/README.md`.
